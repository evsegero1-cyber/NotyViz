# NotyViz

Android-приложение: открывает ноты и табы и показывает их как падающие ноты на клавиатуре пианино или на грифе гитары/баса, со звуком. Работает без интернета.

**Скачать APK:** страница Releases → последняя сборка → `NotyViz.apk`.

## Форматы
- **PDF Songsterr, включая партии ударных** (нотоносец с крестиками и головками распознаётся в инструменты General MIDI) — распознавание строя, тактов, темпа, ладов, лиг и ритма; оригинальная страница с отмеченными нотами и ручная правка.
- **MIDI** (.mid, .midi) — все дорожки, инструменты по General MIDI, для гитары/баса аппликатура подбирается автоматически.
- **Guitar Pro** (.gp, .gp3, .gp4, .gp5, .gpx) и **MusicXML** — дорожки, строй, струны и лады из файла, нотный вид и табулатура.

## Режимы
- **Клавиши** — падающие ноты, руки разными цветами (по дорожкам/станам или по высоте), несколько дорожек сразу.
- **Гриф** — лента табулатуры, ноты подлетают к ладам, позиции подсвечиваются на грифе; для баса — свой гриф.
- **Ноты** — партитура и табулатура с курсором (Guitar Pro, MusicXML).
- **Барабаны** — дорожки по инструментам установки (крэш, хай-хэт, малый, бочка, томы, райд), площадки подсвечиваются при ударе, по ним можно стучать пальцем.
- **Оригинал** — страницы PDF с рамками распознанных нот.

- **Во весь экран** (кнопка ⛶ или поворот телефона на «Клавишах») — альбомная клавиатура с правильными пропорциями клавиш, компактные кнопки сверху, выход — ✕.

Плеер: пуск/пауза, перемотка, такт вперёд/назад, скорость 25–150 %, повтор фрагмента, метроном, громкость, отключение дорожек, сдвиг на октаву.

## Звучание
Для каждой дорожки можно выбрать инструмент из 128 инструментов General MIDI («Дорожки» → «Звучит как»), например электрогитару как рояль.

## Объединение файлов
«Объединить файлы» на главном экране: несколько файлов (MIDI, Guitar Pro, MusicXML, PDF) → список дорожек (выбрать, переименовать, звучание) → синхронизация с основным файлом (по тактам или по реальному времени, смещение в тактах или мс, «Выровнять начало»), предупреждения о разном темпе, размере и начале партий → прослушивание → сохранение проекта. Исходные файлы не меняются.

**Умное объединение фортепиано:** если среди файлов есть партии левой и правой руки (LH/RH, Left/Right, «левая/правая»), они объединяются в одну партию фортепиано с раскраской рук; приложение проверяет октавы рук и предлагает исправить, если левая звучит выше правой. У каждой дорожки можно сдвинуть октаву и выбрать руку.

**Редактор композиции:** включение/выключение и громкость дорожек, «слушать одну», темп всей композиции, сдвиг дорожки (такты, доли, мс), удаление, переименование, экспорт в MIDI и MusicXML с отдельными дорожками.

## Техники исполнения
Модуль `techniques.js` — единая система техник: у каждой ноты есть высота, время, длительность, динамика, инструмент и набор техник с параметрами; у дорожки — кривая подтяжек и педаль.
- **Guitar Pro / MusicXML** (через alphaTab): hammer-on/pull-off, слайды, бенды и release, вибрато, трели, тэппинг, palm mute, флажолеты (NH/AH/PH/TH/SH), тремоло, глухие и призрачные ноты, let ring, удары вверх/вниз, расщипанные аккорды, рычаг, слэп/поп, расгеадо; стаккато, акцент, маркато, тенуто, легато, группетто, морденты, глиссандо, форшлаги, арпеджио, ферматы, педаль, крещендо/диминуэндо, динамика, триоли, 8va.
- **MIDI**: подтяжки (бенд/вибрато по pitch bend), педаль (CC 64), динамика по громкости.
- **PDF Songsterr**: только то, что реально есть в файле — акценты, маркато, стаккато (значки над станом), надписи P.M., let ring, N.H./A.H./P.H., T, L.H./R.H.
- **Звук**: синтезатор строит MIDI с подтяжками, педалью, отдельными тембрами для P.M./глухих нот и флажолетов; трели, тремоло, морденты, глиссандо, арпеджио и стаккато разворачиваются в реальные ноты. Картинка строится из тех же событий.
- **Картинка**: на грифе — слайд движется по ладам, бенд и вибрато сдвигают точку поперёк струны, флажолеты — ромбом, P.M. — штриховкой, тэппинг — кольцом, h/p и слайды — дугами в табулатуре; на клавишах — яркость по динамике, значки стаккато/акцентов, легато-дуги, арпеджио, ферматы, полоса педали.
- **Подсказки**: нажатие на обозначение открывает карточку с символом, объяснением, способом исполнения и анимацией; список техник партии — в «Нотах по тактам». Отключаются в настройках.

## Устройство
`app/src/main/assets/`: `parser.js` — разбор PDF, `import-midi.js`, `import-gp.js` — импорт, `model.js` — общая модель и сборка MIDI, `engine.js` — звук (синтезатор alphaTab, SoundFont Sonivox), `views.js` — клавиатура и гриф, `pdfview.js` — оригинал PDF, `techniques.js` — техники исполнения, `merge.js` — объединение и синхронизация, `export.js` — экспорт MIDI/MusicXML, `app.js` — интерфейс.
Библиотеки: pdf.js, alphaTab (MPL-2.0), @tonejs/midi.
