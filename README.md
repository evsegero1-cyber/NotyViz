# NotyViz

Android-приложение: открывает PDF-табулатуры из Songsterr и показывает партию на клавиатуре пианино с падающими нотами и звуком. Работает без интернета.

**Скачать APK:** страница Releases → последняя сборка → `NotyViz.apk`.

## Что умеет (версия 0.1)
- Открыть PDF кнопкой, из «Загрузок» или через «Поделиться».
- Распознаёт строй, номера тактов, темп, размер, цифры ладов (включая двузначные и ноты в скобках), лиги и ритм (половинные, четверти, восьмые, шестнадцатые, точки).
- Падающие ноты, подсветка клавиш, звук пианино (сэмплы), деление на руки по высоте.
- Скорость 25–150 %, повтор фрагмента по тактам, метроном, перемотка, сдвиг на октаву.
- Список распознанных нот по тактам для проверки.

## Устройство
- `app/src/main/assets/` — само приложение (HTML/JS): `parser.js` — разбор PDF, `app.js` — плеер и отрисовка.
- `lib/` — pdf.js, `samples/` — сэмплы пианино (Salamander, через tonejs-instruments).
- APK собирается GitHub Actions при каждом коммите.
